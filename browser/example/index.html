ตัวอย่างการใช้งาน

ตัวอย่างนี้ ไม่เรียกเซิร์ฟเวอร์จริง — ใช้ api ปลอมที่บันทึกลง console ด้านล่างแทน เพื่อให้เห็นว่าโมดูลตัดสินใจอะไรบ้างโดยไม่ต้องมี backend ตอนใช้งานจริงให้แทนที่ด้วย Proctor.createApi({baseUrl: '/api/proctor'}) ซึ่งจะยิงไปที่ backend ของคุณ (ดู src/api.js)

ตั้ง เม้าหยุดนิ่ง 8 วินาที เตือนล่วงหน้า 4 วินาที — อย่าขยับเม้าแล้วดูว่าเกิดอะไรขึ้น หรือลองสลับแท็บดู

ตัวอย่างนี้ตั้ง video: null คือไม่มีสื่อให้คุม เหมือนกรณีทำข้อสอบ — ทุกการตรวจจะทำงานตลอดเวลาที่หน้าเปิดอยู่
ถ้าคุณมีวิดีโอจริง ส่ง element เข้าไปแทน โมดูลจะ หยุดวิดีโอ เมื่อพบความผิดปกติ และจะไม่ตรวจอะไรเลยระหว่างที่วิดีโอหยุดอยู่ เพราะการหยุดดูเองไม่ใช่ความผิด
